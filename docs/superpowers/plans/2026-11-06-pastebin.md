# Pastebin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A FastAPI pastebin with a web page and a JSON API. Pastes expire after a chosen lifetime. Postgres and Nginx run in Docker, and the app and a cleanup job run under systemd user units plus cron. The user deploys it by hand from a runbook.

**Architecture:** The code has three layers: routes (`app/routes/web.py` for HTML, `app/routes/api.py` for JSON) → `app/service.py` (business rules: TTLs, ID generation, validation) → `app/repository.py` (SQL via SQLAlchemy). Expiry has two layers: every read filters `expires_at > now()`, and `python -m app.cleanup` deletes expired rows on a schedule. Nginx (Docker, host network) listens on `:8080` and proxies to uvicorn on `127.0.0.1:8000`. Postgres runs in Docker and is published on `127.0.0.1:5442`.

**Tech Stack:** Python 3.12, uv, FastAPI, Jinja2, SQLAlchemy 2.0 (sync), psycopg 3, pydantic-settings, Alembic, pytest + httpx (TestClient), Docker Compose (postgres:17, nginx:1.27), systemd user units, cron.

**Spec:** `docs/superpowers/specs/2026-11-06-pastebin-design.md`

## Global Constraints

- Code must be readable by a learner: plain functions, no clever abstractions, short docstrings that explain *why*.
- Git: authored only by the user's identity (`nish8d`). **No `Co-Authored-By` or any Claude attribution trailer.** Commit and push **only at the three milestones** marked below, not per task.
- Nothing outside `pastebin/` is changed by the builder. The user runs all system-changing commands (compose up, systemctl --user, crontab) during Task 9.
- Ports: app `127.0.0.1:8000`, nginx `:8080`, deploy Postgres `127.0.0.1:5442`, test Postgres `127.0.0.1:5443` (5432 is already taken on this machine).
- TTL options, exact keys and durations: `1m` (1 minute), `10m` (10 minutes), `1h` (1 hour), `1d` (1 day), `1w` (7 days).
- Paste IDs: 8 characters from `[A-Za-z0-9]`, generated with `secrets`.
- Max paste size: 512 KiB (524288 bytes, measured as UTF-8). Content is stored exactly as submitted (no stripping), but content that is empty or only whitespace is rejected.
- Config is read from `.env` (`DATABASE_URL`, `BASE_URL`). `.env.example` is committed and `.env` is gitignored.
- No linger. Compose services use `restart: unless-stopped`. The app unit uses `Restart=on-failure`.

## Review Focus

1. **Oversized paste** (> 512 KiB, including multibyte text that is under the limit in characters but over it in bytes) → API returns 413 and the form re-renders with an error. It should never produce a 500. Tests go in Task 3 and Task 5.
2. **HTML/JS in a paste** (`<script>alert(1)</script>`) → shown as literal text on the paste page, never executed. Test goes in Task 5.
3. **Tampered or unknown TTL** (`ttl=99y` from a forged form or curl) → API returns 422 and the form returns 400 with an error. It should never default silently. Tests go in Task 4 and Task 5.
4. **Path collisions**: `/static/...`, `/api/...`, `/healthz`, `/favicon.ico` must never be treated as paste IDs. The paste route only matches `^[A-Za-z0-9]{8}$`. Test goes in Task 5.
5. **Expired but not yet cleaned up** → 404 on both the HTML and JSON reads. Running cleanup twice in a row is safe (the second run deletes 0). Tests go in Task 3 and Task 6.

### Task 3: Service (business rules)

**Files:** Create `app/service.py`, `tests/test_service.py`

**Interfaces:**
- Consumes: repository functions.
- Produces:
  - `TTLS: dict[str, timedelta]` holds the 5 keys from Global Constraints, in order. `TTL_LABELS: dict[str, str]` maps each key to a label: `"1 minute"`, `"10 minutes"`, `"1 hour"`, `"1 day"`, `"1 week"`.
  - `MAX_CONTENT_BYTES = 524288`, `ID_LENGTH = 8`, `ID_ALPHABET = string.ascii_letters + string.digits`.
  - `generate_id() -> str`.
  - Exceptions: `class PasteError(Exception)` with subclasses `EmptyContent`, `ContentTooLarge`, `InvalidTTL`.
  - `create_paste(session, content: str, ttl: str) -> Paste`: validates content (empty or whitespace-only → `EmptyContent`; more than `MAX_CONTENT_BYTES` UTF-8 bytes → `ContentTooLarge`) and the ttl (→ `InvalidTTL`). It sets `created_at = datetime.now(UTC)` and `expires_at = created_at + TTLS[ttl]`, and commits. On an `IntegrityError` from a duplicate id it rolls back and retries with a new id, up to 5 attempts, then re-raises.
  - `get_paste(session, paste_id: str) -> Paste | None`: delegates to `get_live_paste`.

  - `test_create_preserves_whitespace`: content `"  a\n\n"` comes back exactly the same
